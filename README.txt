SHOPIFYCRAFT PORTFOLIO
========================

Pages:
- index.html       Home
- services.html    Shopify services
- portfolio.html   Portfolio and project filters
- about.html       About, testimonials and contact
- images/owner.png Your uploaded owner photo

Everything uses only HTML, CSS and JavaScript.
CSS and JavaScript are inline inside each HTML file.

BEFORE LAUNCH:
1. Open about.html.
2. Replace YOUR_EMAIL@gmail.com in the sendMessage function and Email Me button with your real Gmail address.
3. Replace 2340000000000 in the WhatsApp link with your real WhatsApp number (international format, no +, spaces or brackets).
4. Replace the temporary portfolio images with real Shopify project screenshots.
5. Replace the temporary testimonials with genuine client feedback.
6. Test every navigation link on mobile and desktop.

HOW TO RUN:
Open index.html with Live Server in VS Code.

HOW TO LAUNCH:
Upload the whole folder to your static hosting provider and connect your domain.
